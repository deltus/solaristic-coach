# Solaristic Coach

A phone-first team and squad manager for junior sport coaches: attendance, fair game time with subs, line-ups, quick ratings, balanced teams, drills and season summaries. Everything stays on the coach's phone.

Sister app of [Solaristic Radar](https://github.com/deltus/solaristic-pulse).

- Live: https://deltus.github.io/solaristic-coach/
- Previews: https://deltus.github.io/solaristic-coach/preview/

```bash
npm install
npm run lint:install
npm run dev
npm test
```
